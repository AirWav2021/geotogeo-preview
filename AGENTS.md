# AGENTS.md — Инструкции для агента

## Проект: GeoToGeo

## LLM Wiki — Два уровня

Агент работает с **двумя уровнями wiki**:

### Глобальная: `~/.wiki/`

Общие знания, переиспользуемые между проектами:
- Технологии, фреймворки, библиотеки
- Ресерч результаты
- Известные баги технологий
- Архитектурные паттерны

### Проектная: `.wiki/`

Специфика этого проекта:
- Архитектура, модули, плагины
- Проектные баги и костыли
- Конвенции проекта

### Обязательные правила

1. **Перед любой задачей** — читай `~/.wiki/index.md` и `.wiki/index.md`
2. **Общее знание** → записывать в `~/.wiki/` (технологии, паттерны)
3. **Специфичное знание** → записывать в `.wiki/` (проектные сущности, фиксы)
4. **Новый проект** — регистрировать в `~/.wiki/projects/index.md`
5. **После изменений** — обновлять оба index.md

### Что куда

| Знание | Куда |
|--------|------|
| Свойство технологии/фреймворка | `~/.wiki/entities/` |
| Сущность конкретного проекта | `.wiki/entities/` |
| Глобальный баг технологии | `~/.wiki/fixes/` |
| Проектный баг | `.wiki/fixes/` |
| Переиспользуемый паттерн | `~/.wiki/patterns/` |
| Ресерч | `~/.wiki/research/` |

### Когда обновлять wiki

| Событие | Действие |
|---------|----------|
| Новая зависимость в коде | Добавить сущность + связь (глобально или локально) |
| Изменение архитектуры | Обновить architecture.md в проектной wiki |
| Новый плагин / модуль | Создать страницу в entities/ |
| Найден баг / костыль | Записать в fixes/ (глобально или локально) |
| Проведён ресерч | Записать в research/ |
| Изменились правила | Обновить conventions.md |

## Общие правила

- Перед изменением кода — проверить обе wiki на известные фиксы и связи
- После изменения кода — обновить wiki если затронута архитектура или сущности
- Всегда объяснять в коммитах что и почему, со ссылками на wiki-страницы
